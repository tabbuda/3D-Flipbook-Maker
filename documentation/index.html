3D Digital Flipbook Studio

Interactive, Realistic 3D Page-Turning Flipbook Creator with Zero-Dependency Standalone HTML Export, Multi-Block Editor, and Built-in Image Cropper.

1. Overview

3D Digital Flipbook Studio is a complete, production-ready web application built with React, TypeScript, and Tailwind CSS. It allows users to convert PDFs, images, and rich text into ultra-realistic 3D digital publications with real double-sided page physics, dynamic lighting, drop shadows, and synthesized paper sound effects.

Standout Feature: Exported flipbooks are completely self-contained single-file HTML files with all images embedded as Base64. They work 100% offline in any modern browser without requiring any server, Node.js, or external database!

2. Key Features

Realistic 3D Physics

Double-sided page leaves, interactive mouse drag, corner page curls, and acoustic paper sounds.

20+ Curated Templates

Ready-to-use publication styles: Magazines, Catalogs, Cookbooks, Pitch Decks, Manga, and Brochures.

Interactive Image Cropper

Desktop & mobile friendly popup with 8 resize handles, zoom slider, 90° rotation, and aspect ratio presets.

Single-File HTML Export

Export entire flipbook as an offline-ready .html file with embedded Base64 artwork and interactive 3D reader.

PDF Import Engine

Automatic client-side PDF rasterization into interactive multi-page 3D flipbook albums.

Multi-Block Page Editor

Add, reorder, and configure text, quotes, galleries, image showcases, buttons, and callout blocks.

3. Installation & Quick Start

Follow these quick steps to get the studio running on your local machine:

Prerequisites

  • Node.js: v18.0.0 or higher recommended
  • NPM or Yarn or PNPM

1. Install Dependencies

npm install

2. Run Development Server

npm run dev

Open your browser and visit http://localhost:3000.

3. Build for Production

npm run build

This generates the fully optimized, minified distribution files inside the dist/ directory.

5. Build & Deployment

Because the app is built as a pure client-side SPA with optional server-side proxy capabilities, it can be deployed anywhere in seconds:

  • Vercel: Connect your GitHub repository or run vercel --prod.
  • Netlify: Drag and drop the dist/ folder or connect Git with build command npm run build and publish directory dist.
  • Shared Hosting (cPanel / Apache / Nginx): Upload the contents of the dist/ folder to public_html/.
  • Cloud Run / Docker: Fully compatible with standard containerized web servers.

6. Standalone HTML Export Explained

When users click "Download Standalone HTML", the application executes src/utils/exportHtml.ts:

  1. It clones all project pages, content blocks, titles, and layout parameters.
  2. It converts all external image URLs (Unsplash, local uploads, covers) into high-resolution Base64 Data URLs.
  3. It injects a complete standalone 3D physics rendering engine directly into the generated HTML file.
  4. The resulting single .html file can be emailed, shared on a USB drive, or double-clicked to open on any browser offline.

7. Customization & Theming

You can easily add new templates or customize colors:

  • Adding New Templates: Open src/data/templates.ts and add a new entry to the PUBLICATION_TEMPLATES array.
  • Styling & Fonts: Modify src/index.css or index.html to include custom Google Fonts or Tailwind theme extensions.
