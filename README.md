## ✨ Features

- **Realistic 3D Physics Engine**: Double-sided page leaves, authentic corner curling, mouse drag interaction, dynamic shadow casting, and synthesized page-turn sound effects.
- **Zero-Dependency Standalone HTML Export**: Export entire publications into a single `.html` file with embedded Base64 artwork that runs 100% offline without any server.
- **Built-in Image Cropper**: Modal cropper with 8 resize handles, zoom slider (80%–250%), 90° rotation, and preset aspect ratios (Freeform, 1:1, A4, 4:3, 16:9, 3:4, 9:16).
- **20+ Publication Templates**: Broadsheet Newspapers, Scandi Catalogs, Cookbooks, Travel Guides, Pitch Decks, Corporate Brochures, Manga, and Lookbooks.
- **Multi-Block Modular Editor**: Custom headers, quotes, split image-text sections, bullet lists, stats counters, callouts, and multi-image galleries.
- **Client-Side PDF Rasterizer**: Convert multi-page PDF documents into interactive 3D digital flipbooks in seconds.
- **Dedicated Fullscreen Reader Mode**: Clean distraction-free reading experience with thumbnail navigation, zoom controls, and audio toggles.
- **PWA & Mobile Responsive**: Designed for desktop precision and mobile touch gestures with 44px+ hit targets.

## 🚀 Quick Start

### Prerequisites
- [Node.js](https://nodejs.org/) v18.0.0 or later
- npm, yarn, or pnpm

### 1. Install Dependencies
```bash
npm install
```

### 2. Run in Development Mode
```bash
npm run dev
```
Open your browser at `http://localhost:3000`.

### 3. Build for Production
```bash
npm run build
```
The optimized production files will be output to the `dist/` directory.
